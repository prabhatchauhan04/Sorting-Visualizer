# Sorting Visualizer 🔍📊

A dynamic and interactive web-based **Sorting Algorithm Visualizer** built using **HTML, CSS, and JavaScript**. Watch how sorting algorithms rearrange data step by step using colorful animations!

---

## 🚀 Live Demo

* https://prabhatchauhan04.github.io/Sorting-Visualizer/ *

---

## ✨ Features

- Visualize 5 popular sorting algorithms:
  - 🫧 Bubble Sort
  - 🔽 Selection Sort
  - ➕ Insertion Sort
  - 🔀 Merge Sort
  - ⚡ Quick Sort
- Adjustable **array size**
- Set **animation speed** (1x to 16x)
- Highlights comparisons and swaps using **color-coded bars**
- Final sorted bars shown in **green**

---

## 🛠️ Technologies Used

- **HTML5** – Layout and structure
- **CSS3** – Styling and responsive design
- **JavaScript (ES6+)** – Logic and animations
